    Environment stability — QA / UAT

    Before running real tests, it probes each environment several times and reports right here whether it is stable, unstable, or not responding: if an environment comes back unstable, the warning stays visible on this screen and in the downloadable report, so you do not run the suite against a down environment and mistake its failures for failures in your tests. Criteria: unstable if at least 1 probe fails, if average latency exceeds 1,500 ms, if a single probe exceeds 3,000 ms, or if variation between probes exceeds 1,000 ms.

      How the engine works

      It is not search-and-replace: it reads the structure and rewrites while preserving intent.

      1. Reads and classifies the classWith @Test it goes to tests/; with @FindBy/WebElement and no @Test it is a Page and goes to pages/; a base with @Before/@After and a shared driver goes to fixtures/ as an extended test; static methods with no driver go to utils/. It also reads unannotated methods and preserves them as helpers.
      2. Interprets the metadataEach TestNG annotation is mapped to its Playwright hook or test, with groups, priority, and timeout.
      3. Extracts the data@DataProviders become typed arrays with the same rows and columns.
      4. Rewrites the bodyLocators, actions, waits, and assertions line by line; everything asynchronous gets its await.
      5. Flags what is uncertainAlerts, old-style screenshots, or custom libraries with no equivalent are left as // TODO with a warning, for human review.
      6. Validates equivalenceCompares original and generated code without running: test count and names, assertions, @DataProvider rows, URLs, locators, hooks, and TODOs. The report stays above and, for projects, as VALIDATION.md inside the downloaded .zip.
      7. Validates the environment before runningProbes QA and UAT several times from the stability panel and reports in the UI which one is stable, unstable, or not responding, with latencies and check time. The same check ships as tests/env-stability.spec.ts to run with Playwright before the real suite.
